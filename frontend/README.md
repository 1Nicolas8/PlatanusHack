# Hippocamp frontend

Prototipo navegable del onboarding y estudio de copy. Por ahora el análisis de LinkedIn y la audiencia son estados simulados; el punto de integración futuro está en el envío del formulario dentro de `src/App.jsx`.

```bash
npm install
npm run dev
```

## Flujo incluido

1. Ingreso y validación de una URL pública de LinkedIn.
2. Estado de análisis progresivo del perfil, red y señales.
3. Estudio personalizado para pegar un copy y preparar su simulación.

La interfaz implementa los tokens del design system entregado: lino, terracota, verde oliva, Instrument Serif y Archivo.
